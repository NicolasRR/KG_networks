# Knowledge critical sub-networks

This repository contains the code for the second chapter of my 
[Master thesis](https://drive.google.com/file/d/1R3b8iiiF_DdCWj1jOmg2F25tC8M5JCTP/view?usp=sharing). Here I perform different ablation studies to explore the functional specialization within LLMs. Furthermore, this repository contains the code to train a differentiable mask over the LLMs parameters to ablate knowledge critical subnetworks.
